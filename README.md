# Part 1: Conceptual Design

The goal of our project is to effectively capture and assess exercise movements to provide holistic feedback. A tool that detects exercises in the gym, specifically weighted movements using dumbbells or machines, would serve as an effective way for athletes, gym rats, and even individuals new to the gym to get real-time feedback on their form, allowing them to workout more effectively and minimize injury risk.
